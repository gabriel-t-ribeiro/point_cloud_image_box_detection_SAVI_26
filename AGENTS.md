# Agent guidelines – Trabalho1 (SAVI)

AI use is encouraged in this course, but at the presentation we must be able to
explain every part of the code and change it live. So:

- You may write and edit code, but before each change explain what it does and why
  (theory/math behind it, which Open3D/NumPy/OpenCV functions, and their parameters).
- Keep changes small and step by step; no big rewrites without us asking.
- After each change, tell us how to test it and what result to expect.
- When there are several ways to do something, list them with pros/cons and let us choose.
- Point out which parameters we should experiment with ourselves.
- Our code goes in `gw`. Do not edit `SAVI_26-27/` (professor's material).
